SAITARI DEMO UPDATE

Files included:
- index.html: updated dashboard, website selection on new requests, website details, and image removal confirmation.
- requests.html: shared app navigation, status/priority/website filters, search, responsive layout, and opening a request back in the dashboard panel.
- websites.html: projects/websites directory for Saitari, Kritivela, Calendrai, Portfolio, Run, Jane, Run!, Football Quiz, and Fun Quiz.
- portfolio.html: Greek Saitari case study and demo links.

To apply:
1. Replace index.html and requests.html in the GitHub repository with the included versions.
2. Add websites.html and portfolio.html to the repository root.
3. Commit the four files. Cloudflare Pages will deploy the update from main.

Demo data uses localStorage. Request/project data is local to the browser and is not shared between users.
